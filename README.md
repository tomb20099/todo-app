# TaskMaster Pro - Advanced To-Do List Application

A full-featured, production-ready to-do list application with advanced functionality, cloud sync, teams, analytics, and monetization.

## 🚀 Features

### Core Features
- ✅ Add, edit, delete tasks with rich descriptions
- ✅ Multiple task lists/projects
- ✅ Subtasks and dependencies
- ✅ Recurring tasks (daily, weekly, monthly)
- ✅ Due dates with smart reminders
- ✅ Priority levels and custom categories
- ✅ Tags for better organization
- ✅ Search and advanced filtering
- ✅ Drag & drop reordering

### Advanced Features
- ✅ Team collaboration (invite users)
- ✅ Task assignments and @mentions
- ✅ Comments and activity timeline
- ✅ Time tracking per task
- ✅ Recurring task templates
- ✅ Kanban board view
- ✅ Calendar view
- ✅ Analytics dashboard

### Monetization
- ✅ Free tier (5 tasks, 1 list)
- ✅ Premium tier ($4.99/month) - unlimited tasks, teams
- ✅ Pro tier ($9.99/month) - advanced features, priority support
- ✅ Stripe integration for payments
- ✅ Subscription management
- ✅ Trial period (14 days)

### Technical
- ✅ Local storage + cloud sync (Firebase)
- ✅ Offline-first architecture
- ✅ Progressive Web App (PWA)
- ✅ Mobile responsive
- ✅ Dark mode
- ✅ Multi-language support
- ✅ Export/import (JSON, CSV)

## 🔧 Setup

### Quick Start
```bash
# Clone repo
git clone https://github.com/tomb20099/todo-app.git
cd todo-app

# Open in browser
open index.html

# Or with Python server
python -m http.server 8000
# Visit http://localhost:8000
```

### Deploy (Free Options)
- **Netlify**: Connect GitHub, auto-deploy
- **Vercel**: Same as Netlify
- **GitHub Pages**: Enable Pages in settings
